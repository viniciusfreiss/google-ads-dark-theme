# Google Ads Dark Theme

Simple, high-contrast dark mode for Google Ads.

I built this because I spend all day in Google Ads and the white background was killing my eyes. It uses a smart invert filter but keeps the charts and scorecards readable (so your conversion data doesn't look weird).

## What it does

- **Dark Grey Background**: Uses a balanced `#505050` grey that's easy on the eyes.
- **Readable Charts**: Graphs and KPIs stay correct, not inverted.
- **Clean UI**: Tweaked the menus and tables to actually look good in dark mode.

## How to install

Since it's not on the store yet:

1. Download/Clone this repo.
2. Go to `chrome://extensions` in Chrome.
3. Turn on "Developer mode" (top right).
4. Drag and drop the folder here.

That's it.
